# 知识图谱投资参考优化 - AI算力硬件领域

## 📋 优化概述

本次优化将知识图谱从单纯的知识展示升级为**具有投资参考价值的决策辅助系统**，特别针对AI算力硬件领域提供专业的市场数据和投资信号。

## ✨ 核心功能

### 1. 市场数据增强服务
为每个图谱节点提供实时市场数据：
- 📊 **行业指数表现**：1日/5日/30日涨跌幅
- 💰 **ETF跟踪数据**：跟踪ETF、资金流入、溢折价率
- 💸 **资金流向**：主力净流入、资金情绪指数
- 📰 **新闻热度**：热点标记、情感分析、高频关键词
- 👥 **市场认知**：机构/散户关注度

### 2. AI算力硬件专属指标
针对AI算力硬件领域的特殊指标：
- 🎮 **GPU供应紧张度**（0-100）
- 💾 **HBM供应状态**（tight/normal/loose）
- 🚀 **NVIDIA产品周期**（发布前/发布/成熟/衰退）
- ☁️ **云厂商需求**（strong/moderate/weak）
- 🏢 **数据中心资本开支**

### 3. 智能投资信号
基于市场数据自动生成投资建议：
- ✅ GPU供应紧张 - 上游受益
- ✅ HBM供应紧张 - 存储芯片受益
- ✅ 数据中心建设周期 - 全产业链受益
- ✅ 液冷技术突破 - 散热产业链机会
- ✅ CPO技术落地 - 光通信机会
- ⚠️ 主力资金流出 - 风险警告
- ⚠️ 市场情绪过热 - 回调预警
- 📈 NVIDIA新品发布前 - 提前布局
- 📈 底部反转信号 - 布局机会

## 🚀 快速开始

### 1. 运行数据增强脚本

为AI算力硬件节点添加行业指数关联：

```bash
cd /Users/jozen.lee/ai-softwares/ai-invest
npx tsx scripts/enhance-ai-compute-nodes.ts
```

### 2. 启动开发服务器

```bash
npm run dev
```

### 3. 访问图谱探索页面

打开浏览器访问：`http://localhost:3000/graph/explore`

### 4. 使用市场数据功能

1. 点击"显示市场数据"按钮
2. 点击任意AI算力硬件相关节点
3. 查看右侧显示的：
   - 节点详情
   - **投资参考**（智能投资信号）
   - **市场数据面板**（行业指数、ETF、资金流向等）

const result = await response.json()

// result.data 包含：
{
  id: string,

  marketData: {
    indexPerformance: {...},
    etfTracking: [...],
    capitalFlow: {...},
    newsHeat: {...},
    marketCognition: {...},
    aiComputeMetrics: {...}
  }
}
```

// result.data 包含：
{
  nodes: [...],  // 每个节点包含 marketData
  edges: [...]
}
```

## 📈 投资决策流程

```
1. 选择感兴趣的领域节点（如"芯片设计"、"服务器"）
   ↓
2. 查看投资信号面板
   - 信号类型：机会 / 风险 / 中性
   - 信号强度：60%-100%
   - 风险等级：低 / 中 / 高
   ↓
3. 查看市场数据面板
   - 行业指数：判断大盘走势
   - ETF跟踪：找到可投资标的
   - 资金流向：确认机构态度
   - 新闻热度：了解市场共识
   ↓
4. 结合AI算力指标（如有）
   - GPU供应紧张度：判断供需关系
   - NVIDIA产品周期：把握产品节奏
   - 云厂商需求：判断下游拉动
   ↓
5. 做出投资决策
   - 买入：信号强度高、风险低、资金流入
   - 观望：信号不明确、市场震荡
   - 减仓：过热警告、资金流出、风险高
```

## ⚙️ 配置说明

### 自定义投资信号规则

编辑 `src/lib/config/ai-compute-investment-rules.ts` 可以：
- 添加新的投资信号
- 调整信号触发条件
- 修改风险等级
- 定制投资建议文案

### 扩展到其他领域

要为其他领域（如新能源、消费）添加类似功能：

1. 在 `enhance-ai-compute-nodes.ts` 中添加该领域的节点类型
2. 在 `ai-compute-investment-rules.ts` 中定义该领域的投资规则
3. 在 `graph-market-data.service.ts` 中添加领域特定指标

## 🎯 核心优势

### 对比传统知识图谱

| 维度 | 传统知识图谱 | 优化后 |
|------|-------------|---------|
| **数据类型** | 静态结构数据 | 结构+实时市场数据 |
| **投资参考** | 仅有产业链关系 | 指数、ETF、资金、热度 |
| **决策支持** | 无 | 智能投资信号 |
| **行业深度** | 通用 | AI算力专属指标 |
| **更新频率** | 月级 | 实时/日级 |

### 投资价值

✅ **快速识别机会**：热点板块、资金流入、供需失衡  
✅ **评估投资时机**：产品周期、情绪指标、估值水平  
✅ **构建投资组合**：通过ETF跟踪数据直接投资  
✅ **风险管理**：过热信号、情绪极端、资金流出预警  

## 📝 注意事项

1. **数据时效性**：市场数据需要持续更新，建议每日同步
2. **AI指标准确性**：基于新闻分析，存在一定滞后性
3. **投资风险**：本系统提供参考，不构成投资建议
4. **数据覆盖**：当前主要覆盖A股市场
