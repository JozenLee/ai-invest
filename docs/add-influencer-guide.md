# 添加大V操作指南

## 问题说明

B站 API 有严格的频率限制（错误码 -799 或 -401），即使配置了有效的 Cookie 也容易触发限制。因此添加B站大V时可能会遇到验证失败的情况。

## 解决方案

### 方案一：使用"跳过验证"按钮（推荐）

1. 进入"添加大V"页面
2. 选择平台：**B站**
3. 输入账号ID：**21262795**
4. 点击 **"跳过验证，手动填写"** 按钮
5. 手动填写以下信息：
   - **名称**: 钞能力毛毛（或其他你知道的名称）
   - **主页链接**: https://space.bilibili.com/21262795
   - **头像链接**: （可选）
   - **领域分类**: 财经/科技等
6. 配置监控参数（调度策略、数据保留天数等）
7. 点击"添加大V"完成

### 方案二：等待后自动切换

如果点击了"验证并获取信息"：
1. 系统会尝试验证账号（最多等待5秒）
2. 如果验证超时或失败（频率限制），会显示错误提示
3. **1.5秒后自动切换到手动模式**
4. 按照方案一的步骤5-7继续操作

**超时保护**：验证请求超过5秒会自动中止，不会一直卡在"验证中"状态

## 验证成功的情况

如果B站API可用（没有触发频率限制），验证会成功并自动填充：
- 用户名
- 头像URL
- 主页链接
- 认证状态
- 粉丝数

然后直接配置监控参数即可。

## 技术细节

### 已修复的问题

1. **后端修复** (`data-service/routers/influencers.py`)
   - 添加了 `load_bilibili_config()` 函数从配置文件读取Cookie
   - 验证接口使用配置文件中的Cookie而非空Cookie
   - 改进错误提示信息

2. **前端改进** (`src/components/influencers/PlatformValidator.tsx`)
   - 添加"跳过验证"按钮，允许直接进入手动模式
   - 验证失败时自动切换到手动模式
   - 改进错误处理逻辑

### B站API限制说明

- **错误码 -799**: 请求过于频繁，请稍后再试
- **错误码 -401**: 非法访问
- 即使有有效Cookie，短时间内多次请求也会触发限制
- 建议使用手动模式或等待一段时间后重试
