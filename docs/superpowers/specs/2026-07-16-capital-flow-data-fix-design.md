# 资金流向数据修复与增强设计

## 问题清单

### P0: 北向资金为0
- **根因**: 单位转换bug — AKShare返回的`成交净买额`已是元，`akshare_client.py`又乘1e8，`capital_flow.py`再除1e8，抵消后看似正确但实际有NaN/空值问题
- **修复**: 移除多余的单位转换，直接使用AKShare返回的原始数值

### P0: 市场情绪无有效数据
- **根因**: `capital_flow.py`中sentiment硬编码为35，新闻sentiment字段始终为None
- **修复**: 基于涨跌比、涨停跌停比、成交量等真实指标计算市场情绪

### P1: 板块资金流向数据review
- **问题1**: 多日指标(3日/5日/10日)字段映射错误，始终返回0
- **问题2**: 字段名不统一（`netFlow` vs `mainForceNet`）
- **修复**: 正确映射多日字段，统一字段名

### P2: 补充主流资金流向指标
- 融资融券余额变化
- 大单/超大单净流入
- 行业资金流向热力图数据

## 实施计划

### 1. 修复北向资金数据链路
- `akshare_client.py`: 移除`* 100000000`，直接用原始值
- `capital_flow.py`: 移除`/ 100000000`，添加沪股通/深股通拆分
- 增加文件缓存降级

### 2. 实现真实市场情绪计算
- 基于AKShare的涨跌停数据、涨跌比计算情绪指数(0-100)
- 添加到`capital_flow.py`的market端点

### 3. 修复板块资金流向
- 修复多日指标字段映射
- 统一返回字段名
- 添加文件缓存

### 4. 补充资金流向指标
- 融资融券数据端点
- 大单/超大单数据
- 北向资金历史趋势
