# 调度器对话框布局重构报告

## 🎯 问题解决方案

### 原问题
- 使用滚动容器（ScrollArea / overflow-y-auto）时出现重复显示运行历史组件
- 内容过长需要滚动才能看到所有信息

### 新方案：使用 Tabs 分页布局 ✅

**完全去除滚动**，将内容分为两个标签页：
1. **配置管理** - 基本信息和调度配置
2. **运行历史** - 执行日志记录

---

## ✨ 改进亮点

### 1. 完全去除全局滚动
- DialogContent 不再使用 `max-h-[90vh]` 和 `overflow-y-auto`
- 主内容区使用 Tabs 分页，每个页面内容适中

### 2. 运行历史独立标签页
- 只有运行历史列表使用局部滚动 `max-h-[400px] overflow-y-auto`
- 限制在合理高度内，避免对话框过高
- 只在切换到"运行历史"标签时才显示

### 3. 内容分组更清晰
- **配置管理**：专注于调度器的配置和设置
- **运行历史**：专注于查看历史执行记录
- 用户可快速切换，不需要滚动寻找内容

### 4. 视觉体验优化
- 使用图标增强标签页识别度
  - 配置管理：Settings 图标
  - 运行历史：History 图标
- 保持原有的视觉风格和交互逻辑

---

## 🔧 技术实现

### 关键修改

1. **导入 Tabs 组件**
```tsx
import { Tabs, TabsContent, TabsList, TabsTrigger } from '@/components/ui/tabs';
```

2. **移除滚动容器**
```tsx
// 旧版本
<DialogContent className="max-w-2xl max-h-[90vh] flex flex-col p-0">
  <div className="flex-1 overflow-y-auto px-6">

// 新版本
<DialogContent className="max-w-3xl p-0">
  <Tabs defaultValue="config" className="px-6">
```

3. **内容分页**
- 配置内容放在 `TabsContent value="config"`
- 历史记录放在 `TabsContent value="history"`

4. **局部滚动**
- 仅运行历史列表使用：`max-h-[400px] overflow-y-auto pr-2`
- 限制最大高度，超出时才出现滚动条
