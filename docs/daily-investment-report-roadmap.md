# 每日投资建议闭环路线

## 产品目标

每天针对一个产业或主题，基于统一时间快照，把市场、知识图谱、企业、资讯和持仓信息编译成可执行的组合动作：

- 今天应该做什么，或者明确告诉用户今天不应该交易。
- 动作对应哪个标的、方向、仓位变化和金额。
- 需要什么条件才能执行，什么条件会使判断失效。
- 每个结论都能回溯到原始数据、来源和更新时间。

## 统一处理链路

```text
数据采集 → 时间/代码/价格口径统一 → 异常检测 → 模块信号计算
→ 知识图谱事件映射 → 组合暴露计算 → 跨模块冲突检查
→ 规则质量门禁 → AI 解释与假设 → 结构化校验
→ 每日动作报告 → 执行后回放 → 结果评估
```

## 五个模块的职责

### 市场

输出大盘和主题指数的趋势、相对强弱、技术指标共振、波动率、最大回撤、上涨占比和有效样本比例。异常行情不能进入动作排序。

### 知识图谱

把新闻事件映射到产业链阶段、细分环节、企业和 ETF，计算影响方向、传播范围、受益/受损节点以及结构性机会。

### 企业

区分行情表现、财报事实、公告事件、盈利质量、估值可用性和数据完整度。缺少现金流或估值时，报告必须明确不可判断。

### 资讯

做事件去重、聚类、多源验证、新颖度、影响时间窗口和市场定价判断；新闻标题本身不能直接成为买卖理由。

### 持仓

同步当前价格、净值、权重、盈亏和资产类型，穿透基金/ETF 暴露，计算组合集中度、主题重复暴露、现金比例以及调仓前后变化。

## 动作等级

| 动作 | 允许条件 |
| --- | --- |
| `buy` / `add` | 全部核心模块质量通过，跨模块信号一致，组合权重和金额可计算 |
| `hold` | 现有暴露合理，但新增证据不足 |
| `watch` | 存在潜在机会，但缺少确认信号 |
| `data_review` | 市场异常、组合字段缺失或跨模块时间/代码不一致 |
| `no_action` | 证据不足或风险收益比不满足交易门槛 |

## 当前版本已落地

- 报告契约升级为 `2.0`，加入模块质量分、动作门禁、优先级和金额字段。
- 异常行情从有效样本和动作排序中隔离。
- 持仓缺少当前价格或权重时，禁止计算精确调仓金额。
- 规则引擎支持 `data_review`，不会把质量问题伪装成买入建议。
- AI 输出增加标的、证据、动作权限、目标价和仓位变化一致性校验。
- 市场数据服务与前端规则引擎使用同一套异常样本定义。

## 下一阶段

1. 增加知识图谱事件影响链和 ETF/持仓映射。
2. 增加新闻事件聚类、多源验证和历史事件回测。
3. 补齐组合实时净值、权重、盈亏与底层资产穿透。
4. 增加调仓前后组合模拟和风险预算。
5. 保存每日报告快照，跟踪 1/5/20 个交易日后的结果。
6. 根据历史回放评估建议命中率、误报率和风险调整收益。
