## 🔍 详细分析

### 1. 数据更新链路

```
用户浏览器
    ↓ (初始加载 + 自动刷新)
Next.js API (30秒缓存)
    ↓
Python 服务 (30-600秒缓存)
    ↓
外部数据源 (AKShare/东方财富)
```

### 2. 各层缓存时间

| 层级 | 组件 | 缓存时间 | 影响 |
|------|------|---------|------|
| 前端 | MarketContext | 无缓存 | - |
| API | Next.js | 30秒 | 小 |
| 后端 | Python - 指数 | 30秒 | 小 |
| 后端 | Python - 资金流向 | **600秒** | **中** |

### 3. 刷新机制

**前端自动刷新**:
- 交易时段: 每 30 秒
- 非交易时段: 每 5 分钟 (300秒)

**缓存过期时间**:
- Next.js: 30 秒
- Python 资金流向: 600 秒

**问题**: 前端 5 分钟刷新 vs 后端 10 分钟缓存 → 中间有 5 分钟窗口期返回旧缓存
