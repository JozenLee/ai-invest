# 知识图谱投资参考优化方案

## 概述

针对当前知识图谱投资参考意义较弱的问题，本优化方案将知识图谱与**行业指数**、**ETF表现**、**资金流向**和**市场认知**深度关联，特别针对**AI算力硬件领域**提供专业的投资参考指标。

## 优化内容

### 1. 市场数据增强服务 (`graph-market-data.service.ts`)

为每个图谱节点提供多维度的市场数据：

#### 1.1 行业指数表现
- **1日/5日/30日涨跌幅**：快速判断短中长期趋势
- **成交量和换手率**：衡量市场活跃度
- **估值指标**（PE/PB）：判断是否高估或低估

#### 1.2 ETF跟踪数据
- **跟踪ETF列表**：与节点相关的可投资ETF
- **涨跌幅对比**：了解不同ETF的表现差异
- **溢折价率**：判断买入时机（折价买入更优）
- **5日资金流入**：观察资金流向，判断市场态度

#### 1.3 资金流向
- **主力净流入**：机构资金动向
- **散户净流入**：散户情绪
- **资金情绪指数**（-100~+100）：综合判断市场情绪
- **连续流入/流出天数**：判断趋势强度

#### 1.4 新闻热度
- **7日/30日新闻数**：衡量市场关注度
- **情感得分**：bullish（看多）/neutral（中性）/bearish（看空）
- **热点标记**：快速识别当前热点板块
- **高频关键词**：了解市场讨论焦点

#### 1.5 市场认知指标
- **机构关注度**（0-100）：基于研报、新闻数量
- **散户关注度**（0-100）：基于社交媒体热度
- **分析师覆盖数**：专业机构关注程度
- **搜索热度指数**：公众兴趣程度

### 2. AI算力硬件专属指标

针对AI算力硬件领域的特殊性，提供行业专属指标：

#### 2.1 GPU供应紧张度 (0-100)
- 基于新闻中的供应关键词分析
- 反映市场供需关系
- **投资参考**：紧张度>70时，上游芯片设计、代工企业受益

#### 2.2 HBM供应状态
- tight（紧张）/ normal（正常）/ loose（宽松）
- **投资参考**：紧张时，HBM供应商（SK海力士、美光、三星）及相关产业链受益

#### 2.3 NVIDIA产品周期
- pre_launch（发布前）：概念炒作期
- launch（新品发布）：市场热度最高
- mature（成熟期）：稳定出货
- decline（衰退期）：等待下一代产品
- **投资参考**：launch期上游供应链受益；pre_launch期适合布局

#### 2.4 云厂商需求
- strong（强劲）/ moderate（适中）/ weak（疲软）
- 基于云厂商（AWS、Azure、阿里云等）财报和资本开支分析
- **投资参考**：strong时整个产业链受益

#### 2.5 数据中心资本开支
- 追踪全球数据中心建设投资
- **投资参考**：资本开支增长时，服务器、散热、光模块等受益

## 使用指南

### 3.1 运行数据增强脚本

首先为AI算力硬件节点添加行业指数关联：

```bash
cd /Users/jozen.lee/ai-softwares/ai-invest
npx tsx scripts/enhance-ai-compute-nodes.ts
```

### 3.2 在探索页面使用

1. 访问图谱探索页面：`/graph/explore`
2. 点击"显示市场数据"按钮启用市场数据面板
3. 点击任意节点，右侧会显示：
   - 节点基础信息
   - 市场数据面板（实时指标）
   - 图谱统计

## 投资决策示例

### 场景1：GPU供应链机会识别

**观察指标：**
1. GPU供应紧张度 > 70
2. HBM供应状态 = tight
3. NVIDIA产品周期 = launch
4. 主力资金持续流入 > 3天

**投资建议：**
- 关注芯片设计节点（NVIDIA供应商）
- 关注HBM存储节点（SK海力士、美光）
- 关注封装测试节点（高端封装需求增加）

**对应ETF：**
- 512480（半导体ETF）
- 159995（芯片ETF）

### 场景2：数据中心建设周期

**观察指标：**
1. 云厂商需求 = strong
2. 数据中心节点新闻热度 trending = true
3. 服务器节点主力资金持续流入
4. 相关ETF溢价率 > 2%（市场过热信号）

**投资建议：**
- 一级受益：服务器节点
- 二级受益：散热节点、电源节点、PCB节点
- 三级受益：光模块节点、网络设备节点

**对应ETF：**
- 515070（AI ETF）

### 场景3：新技术突破

**观察指标：**
1. CPO光模块新闻数突增（7日新闻 > 30）
2. 情感得分 > 0.5（强烈看多）
3. 高频关键词包含"突破"、"量产"
4. 散户关注度快速上升（>60）

**投资建议：**
- 关注光通信产业链
- 但需警惕：散户关注度过高可能是炒作顶部信号
- 建议等待回调或机构资金介入

**对应ETF：**
- 515880（通信ETF）

## 技术架构

```
前端 (explore/page.tsx)
    ↓
API层 (/api/graph/nodes/[id]/market-data)
    ↓
服务层 (graph-market-data.service.ts)
    ↓ (并行查询)
    ├─ IndexDaily (指数表现)
    ├─ ETFDaily (ETF数据)
    ├─ SectorCapitalFlow (资金流向)
    ├─ NewsGraphLink + NewsArticle (新闻热度)
    └─ 算法计算 (AI算力指标)
    ↓
返回增强的GraphNode + MarketDataEnhancement
```

## 注意事项

1. **数据时效性**：市场数据需要持续更新，建议每日同步指数、ETF、资金流向数据
2. **AI指标准确性**：AI算力指标基于新闻分析，存在一定滞后性和误差
3. **投资风险**：本系统提供参考，不构成投资建议，投资需谨慎
4. **数据覆盖**：当前主要覆盖A股市场，港股、美股数据需要补充

## 总结

通过本次优化，知识图谱从单纯的结构化知识展示升级为具有实时市场数据、资金流向、情绪分析的**投资决策辅助系统**。

特别是针对AI算力硬件领域，提供了GPU供应紧张度、HBM供应状态、NVIDIA产品周期等专业指标，使投资者能够：

✅ **快速识别投资机会**：热点板块、资金流入、供需失衡  
✅ **评估投资时机**：产品周期、情绪指标、估值水平  
✅ **构建投资组合**：通过ETF跟踪数据直接投资  
✅ **风险管理**：过热信号、情绪极端、资金流出预警  

这使得知识图谱真正成为连接**产业认知**与**投资决策**的桥梁。
