## 🐛 如果发现问题

### 问题 1: 显示旧日期

**解决方案**:
1. 点击「刷新数据」按钮
2. 等待 5 分钟后自动刷新
3. 如果还是旧数据，查看后端日志

### 问题 2: 北向资金为 0

**原因**: 可能是周一，上周五数据未更新
**操作**: 记录到验证报告，不算错误

### 问题 3: 页面报错

**操作**:
1. 检查 Python 服务是否运行
2. 查看浏览器控制台错误
3. 运行诊断脚本: `bash scripts/diagnose-dashboard-data.sh`
