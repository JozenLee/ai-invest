## 八、验收流程

1. **环境准备**
   ```bash
   npm install
   npm run db:migrate
   npm run db:seed
   ```

2. **启动服务**
   ```bash
   # 终端1：Python数据服务
   cd data-service
   pip install -r requirements.txt
   python main.py

   # 终端2：Next.js应用
   npm run dev
   ```

3. **执行验收**
   - 按照本文档逐项测试
   - 记录测试结果
   - 标记通过/失败

4. **问题记录**
   - 记录发现的问题
