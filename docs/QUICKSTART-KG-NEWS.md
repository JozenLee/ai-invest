# 知识图谱与资讯流联动 - 快速使用指南

## 🎉 新功能上线！

**知识图谱与资讯流联动**功能已完成部署，现在可以使用了！

## ✨ 功能亮点

### 1. 动态产业筛选
- 资讯流页面新增"选择产业"筛选器
- 基于知识图谱的产业结构动态生成
- 替代了原有的硬编码分类体系

### 2. 细分领域筛选
- 选择产业后，自动加载该产业的所有细分领域（Segment）
- 支持多选，精准定位感兴趣的环节
- 实时更新新闻列表

### 3. 产业标签显示
- 新闻卡片自动显示关联的产业和细分领域
- 紫色标签醒目标识
- 点击标签可跳转到知识图谱（未来优化）

## 🚀 快速开始

### 方式一：使用快速启动脚本（推荐）

```bash
# 启动所有服务
./scripts/start-services.sh

# 停止所有服务
./scripts/stop-services.sh
```

### 方式二：手动启动

```bash
# 终端 1: 启动 Python 数据服务
cd data-service
python main.py

# 终端 2: 启动 Next.js 应用
npm run dev
```

### 首次使用：初始化数据

```bash
cd data-service
./scripts/init_kg_news_integration.sh
```

这个脚本会：
- 为每个 Segment 生成新闻匹配关键词
- 建立 Segment 与 Tag 的关联关系
- 清除缓存

## 📖 使用方法

### 1. 访问资讯流页面

打开浏览器，访问：http://localhost:3000/events/feed

### 2. 使用产业筛选

1. 点击"选择产业"下拉框
2. 选择一个产业（如："AI硬件"）
3. 自动出现"选择细分领域"筛选器

### 3. 选择细分领域

1. 在"选择细分领域"筛选器中勾选感兴趣的环节
2. 可以多选（如：同时选择"芯片设计"和"芯片制造"）
3. 新闻列表自动更新

### 4. 查看产业标签

- 新闻卡片下方会显示紫色的产业细分领域标签
- 鼠标悬停可以看到完整的产业-领域信息
- 点击标签可跳转到知识图谱（功能持续优化中）

## 🛠️ 常见问题

### Q1: 产业筛选器为空？

**原因**: 知识图谱中还没有产业数据

**解决**:
1. 访问 http://localhost:3000/graph/create
2. 创建至少一个产业图谱
3. 刷新资讯流页面

### Q2: 选择产业后没有细分领域？

**原因**: 该产业的图谱结构不完整

**解决**:
1. 在知识图谱页面编辑该产业
2. 确保添加了阶段（上游/中游/下游）和环节
3. 重新初始化数据

### Q3: 新闻没有产业标签？

**原因**: 新闻还没有关联到知识图谱

**解决**:
1. 确保新闻有 Tag 关联
2. 运行映射脚本：
   ```bash
   cd data-service
   python3 scripts/map_tags_to_segments.py
   ```
3. 刷新页面

### Q4: 筛选后没有新闻？

**可能原因**:
- 该产业/领域确实没有相关新闻
- Tag-Segment 映射不准确

**解决**:
1. 尝试选择其他产业或领域
2. 检查 Neo4j 中的映射关系
3. 优化 Segment 的关键词
