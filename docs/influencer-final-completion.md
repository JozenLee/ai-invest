## 📋 用户使用指南

### 访问入口
```
http://localhost:3000/events/influencers
```

### 基本操作

#### 1. 查看大V列表
- 访问列表页
- 使用平台筛选（6个平台可选）
- 搜索大V名称或账号

#### 2. 添加新大V
- 点击右上角"添加大V"按钮
- 填写表单：
  - 名称 (必填)
  - 平台 (必填，6选1)
  - 账号ID (必填)
  - 其他信息 (可选)
- 提交后自动跳转详情页

#### 3. 查看大V详情
- 在列表页点击大V卡片
- 查看基本信息、分类、标签
- 查看动态列表（待实现）
- 触发数据抓取
