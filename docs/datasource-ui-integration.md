## 🔧 技术实现

### 前端逻辑

```typescript
// 状态筛选
const filteredSources = dataSources
  .filter((s) => categoryFilter === 'all' || s.category === categoryFilter)
  .filter((s) => statusFilter === 'all' || 
    (statusFilter === 'active' ? s.isActive : !s.isActive))

// 统计计算
const activeSources = dataSources.filter((s) => s.isActive).length
const inactiveSources = dataSources.filter((s) => !s.isActive).length
```

### 样式处理

```tsx
// 卡片不透明度
<Card className={cn(
  "rounded-xl shadow-sm transition-all hover:shadow-md",
  !isActive && "opacity-60"  // 禁用时显示为灰色
)}>

// 图标颜色
{isActive ? (
  <Power className="h-4 w-4 text-green-600" />
) : (
  <PowerOff className="h-4 w-4 text-gray-400" />
)}

// 按钮禁用
<Button
  onClick={() => onFetch?.(id)}
  disabled={!isActive}  // 禁用数据源不可采集
>
```

## 🚀 使用指南

### 管理员操作

#### 启用数据源
1. 访问 `/events/sources`
2. 找到禁用的数据源（灰色卡片）
3. 点击 PowerOff 图标
4. 确认状态变为"已启用"

#### 禁用数据源
1. 访问 `/events/sources`
2. 找到需要禁用的数据源
3. 点击 Power 图标
4. 确认卡片变灰，状态变为"已禁用"

#### 筛选数据源
1. 使用"类别"下拉菜单按分类筛选
2. 使用"状态"下拉菜单查看激活/禁用的数据源
3. 两个筛选器可组合使用
