# 资金流向数据计算方法更新

## 更新日期
2026-07-27

## 问题描述
原先的资金流向数据使用零和博弈估算，导致：
- 主力和散户的资金数额完全相反（+908.3亿 vs -908.3亿）
- 主力和散户的占比也完全相反（+8.81% vs -8.81%）
- 虽然数学上正确，但用户体验不直观

## 更新内容

### 1. 后端 API 更新 (`data-service/routers/capital_flow.py`)

**原来的计算方式**：
```python
# 零和博弈估算：散户占比 ≈ -主力占比
retail_pct = round(-main_pct, 2)
```

**新的计算方式**：
```python
# 占比计算：基于成交活跃度（绝对值）
# 这样主力和散户的占比都是正数，表示各自的交易参与度
total_volume = abs(main_net) + abs(retail_net)
if total_volume > 0:
    main_pct = round((abs(main_net) / total_volume) * 100, 2)
    retail_pct = round((abs(retail_net) / total_volume) * 100, 2)
```

**改进说明**：
- 主力和散户的**净额**仍然相反（反映市场零和博弈）
- 主力和散户的**占比**改为正数（反映交易活跃度）
- 占比总和为 100%，更直观易懂

### 2. 前端显示更新 (`src/app/(dashboard)/dashboard/page.tsx`)

**更新内容**：
- 将"占比"改为"活跃度"，更准确描述指标含义
- 更新 tooltip 说明，解释新的计算方式
- 移除"零和博弈估算值"的警告标识
- 优化数据说明卡片的文案

- ⚔️ 主力与散户方向相反，市场存在分歧
- 💡 双方交易参与度各占 50%，说明资金博弈激烈

## 技术细节

### 占比计算公式

**旧公式（零和博弈）**：
```
主力占比 = 主力净流入 / 总成交基数 × 100%
散户占比 = -主力占比
```

**新公式（活跃度）**：
```
总交易额 = |主力净流入| + |散户净流入|
主力活跃度 = |主力净流入| / 总交易额 × 100%
散户活跃度 = |散户净流入| / 总交易额 × 100%
```

### 数据验证

- ✅ 主力+散户占比总和 = 100%
- ✅ 主力和散户的活跃度都是正数
- ✅ 净额仍然保持零和关系（主力+散户≈0）
- ✅ 市场情绪计算未受影响

## 注意事项

- 净额数据仍然保持零和关系（这是市场的真实特征）
- 活跃度只反映交易参与度，不反映方向
- 方向信息通过净额的正负号体现（+表示流入，-表示流出）
- 北向资金在非交易时段为0是正常现象
