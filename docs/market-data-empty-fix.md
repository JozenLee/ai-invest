# 市场数据为空问题 - 解决报告

## 📋 问题描述

**用户反馈**：目前各个节点的市场数据都是空的

## 🔍 问题原因

经过检查发现，数据库中**完全没有市场数据**：

```
IndexDaily 表: 0 条记录          ❌
ETFDaily 表: 0 条记录            ❌
SectorCapitalFlow 表: 0 条记录   ❌
NewsGraphLink 表: 0 条记录       ❌
```

### 为什么市场数据是空的？

**市场数据增强服务** (`graph-market-data.service.ts`) 依赖以下数据表：

1. **IndexDaily** - 指数日线数据
   - 用于计算行业指数表现（1日/5日/30日涨跌幅）
   - 示例：中证人工智能、中证半导体、中证通信设备

2. **ETFDaily** - ETF日线数据
   - 用于显示跟踪ETF的涨跌幅、溢折价率、资金流入
   - 示例：515070 AI ETF、512480 半导体ETF

3. **SectorCapitalFlow** - 板块资金流向
   - 用于分析主力净流入、资金情绪
   - 示例：芯片、服务器、光模块板块

4. **NewsGraphLink** - 新闻与节点关联
   - 用于计算新闻热度、情感分析
   - 关联新闻到图谱节点

**由于这些表都是空的，所以市场数据服务无法获取任何数据。**

## ✅ 解决方案

### 方案1：生成模拟数据（已执行）✅

**脚本**：`scripts/generate-mock-market-data.ts`

**执行命令**：
```bash
npx tsx scripts/generate-mock-market-data.ts
```

**生成的数据**：
- ✅ **90条** 指数日线数据（3个指数 × 30天）

  - 中证全指半导体指数（931865）
  - 中证全指通信设备指数（931160）

- ✅ **120条** ETF日线数据（4个ETF × 30天）
  - 515070 AI ETF
  - 512480 半导体ETF
  - 159995 芯片ETF
  - 515880 通信ETF

- ✅ **210条** 板块资金流向数据（7个板块 × 30天）
  - 芯片、存储芯片、服务器、散热、数据中心、光模块、通信设备

- ✅ **111条** 新闻-节点关联
  - 将现有新闻关联到AI算力节点

- ✅ **11个节点** 的新闻统计（newsCount7d, newsCount30d）

**数据特点**：
- 过去30天的历史数据
- 价格随机波动（±1.5%左右）
- 资金流向有正有负
- 溢折价率在合理范围内（±3%）

## ⚠️ 注意事项

### 模拟数据的限制

1. **数据不真实**
   - 价格走势是随机生成的
   - 不反映真实的市场情况
   - 仅用于功能演示和测试

2. **数据不更新**
   - 模拟数据是静态的
   - 不会自动更新
   - 需要重新运行脚本来刷新

3. **投资信号可能不准确**
   - 因为基于模拟数据计算
   - 不能作为真实投资依据
