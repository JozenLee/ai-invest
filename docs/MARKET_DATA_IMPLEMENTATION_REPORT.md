## ⚠️ 已知问题与限制

### 问题1: 指数数据同步失败
**现象**: 中证指数（930713, 931865, 931160）无法同步  
**原因**: Python数据服务的 `/api/market/index/{code}` 端点存在错误  
**影响**: 图谱节点的"行业指数表现"模块无法显示数据  
**优先级**: 高  
**解决方案**: 
- 短期：调试修复index API
- 中期：使用AKShare的其他指数接口

### 问题2: 部分板块名称未匹配
**现象**: 芯片、存储芯片、散热、光模块等板块无数据  
**原因**: 东方财富的板块分类与项目的板块命名不一致  
**影响**: 部分图谱节点的资金流向数据缺失  
**优先级**: 中  
**解决方案**: 
- 获取完整的东方财富板块列表
- 更新 `SECTOR_MAPPING` 映射表

### 问题3: 缺少指数历史数据
**现象**: IndexDaily表为空  
**影响**: 无法计算指数的涨跌幅趋势  
**优先级**: 高  
**解决方案**: 与问题1同步解决
